********************
Set String Case Node
********************

.. figure:: /images/node-types_FunctionNodeSetStringCase.png
   :align: center
   :alt: Set String Case node.

The *Set String Case* node converts the characters in a string to uppercase or lowercase.


Inputs
======

String
   The string to convert.

Case
   The letter case to apply.

   :Uppercase: Convert all alphabetic characters to uppercase.
   :Lowercase: Convert all alphabetic characters to lowercase.


Outputs
=======

String
   The converted string.
