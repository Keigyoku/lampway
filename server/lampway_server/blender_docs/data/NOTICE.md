This offline corpus ships with Lampway's server. It performs no network retrieval
at runtime. `manifest.json` records source revisions and a SHA256 for every RST.

The API reference was generated by Lampway's built binary using the generator in
the repository's pinned Blender source, commit
`fbe6228777e7d9afefcd61a413844e790ae75db7`. Its native core is Blender 5.2.0,
while `bpy.app.version_string` reports Lampway's branded version `0.1.0`.
API documentation is copyright Blender Authors, GPL-2.0-or-later.

The manual comes from the official
[Blender manual repository](https://projects.blender.org/blender/blender-manual),
`blender-v5.2-release` commit `4a3be8f9ed3b66b24913e0a0d491d3429a70ea08`.
The official repository had no matching 5.2 release tag at acquisition; this
immutable release-branch commit is the pin. Manual documentation is copyright
Blender Documentation Team, CC-BY-SA-4.0. RST files retain their original contents.

Parser, search and API lookup helpers come from
[Blender Lab MCP](https://projects.blender.org/lab/blender_mcp), v1.0.3, commit
`2cea8d566dde07fbac28a61d698909d69724e853`, copyright 2026 Blender Authors,
GPL-3.0-or-later. Lampway changes their imports to package-relative imports and
extracts the API lookup from its MCP registration wrapper. The adapter fixes the
class-member lookup by using the existing parser's qualified class path.

Applicable licence texts are bundled in `licenses/`.

The GPL licence texts are copied verbatim from the pinned Blender source
`release/license/spdx/` at the recorded API upstream commit.
