# rig_convert recipes

`anim-profile-manny.json` holds skeleton facts only: the bone names, hierarchy and reference (rest) joint transforms of the UE5 Manny reference skeleton, measured in Unreal Engine 5.8 through the TITAN project. No Epic mesh, texture or code is included. See [`THIRD_PARTY.md`](../../../../../../../THIRD_PARTY.md).
